# Mi Mapa

Tu carta BaZi traducida a una experiencia visual, cotidiana y fácil de compartir.

La aplicación funciona por completo en el navegador y se publica como sitio estático en GitHub Pages.

Sitio principal: <https://mi-mapa.github.io/>

El catálogo mundial de ciudades se deriva de [GeoNames](https://www.geonames.org/) y se distribuye bajo [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Las zonas horarias usan identificadores de la base IANA.
